# Hackathon-2026 
## Innovacion por la transparencia y anticorrupción

Este repositorio contiene la solución desarrollada para el **Hackathon: Innovación por la Transparencia y Anticorrupción 2026**, evento convocado por el **H. Ayuntamiento del Municipio de Hermosillo** (a través de la Unidad de Transparencia Municipal, el Órgano de Control y Evaluación Gubernamental, el Instituto Hermosillense de la Juventud y la Agencia Municipal de Desarrollo Económico) en alianza con la **Universidad Kino**.

---
## Instalación
```bash
py -m venv .venv
.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```
---
## Activacion de apis
python -m uvicorn api:app --reload
---
## Correr
```bash
streamlit run app.py
```
